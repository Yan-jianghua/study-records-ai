# 新增学习记录

## 使用场景

用户完成今日学习后，希望记录学习历程与笔记，方便以后复习，并供其他 Agent 读取。

## 正常输入示例

- 标题：Python函数
- 内容：Python中函数的定义与使用
- 学习分钟数：30
- 完成状态：已完成

## 保存成功的预期结果

保存后，学习记录列表出现一条新记录。
该记录的标题、内容、学习分钟数和完成状态与输入一致。

## 非法输入与处理规则

学习分钟数必须大于零。

当学习分钟数为 -10 时：
- 提示“学习分钟数错误，请重新填写”。
- 不保存这条记录。

当学习分钟数为 0 时：
- 提示“学习分钟数错误，请重新填写”。
- 不保存这条记录，因为 0 不大于零。
其他 Agent 读取记录的具体方式，后续设计时确定。
